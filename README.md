# Credit Card Financial Analytics Dashboard

## Overview

The Credit Card Financial Analytics Dashboard is a data analytics project designed to analyze credit card customer information and transaction data.

The project uses PostgreSQL and SQL for data storage and analysis, along with Power BI to create interactive dashboards and visualize financial and customer-related insights.

The dashboard focuses on revenue, transaction trends, customer demographics, card categories, and customer financial behavior.

## Project Objectives

* Analyze credit card customer and transaction data.
* Understand revenue and transaction trends.
* Examine customer demographics and card categories.
* Identify patterns in customer spending and financial activity.
* Build an interactive dashboard using Power BI.
* Practice SQL-based data analysis and business reporting.

## Tools and Technologies

* **Database:** PostgreSQL
* **Query Language:** SQL
* **Visualization:** Microsoft Power BI
* **Data Format:** CSV
* **Version Control:** Git and GitHub

## Dataset

The project uses two main categories of data:

1. **Customer Data**

   * Customer demographics
   * Education level
   * Marital status
   * Income
   * Occupation
   * Customer satisfaction score

2. **Credit Card Transaction Data**

   * Card category
   * Annual fees
   * Credit limit
   * Transaction amount
   * Transaction count
   * Interest earned
   * Revenue-related metrics

The dataset is loaded into PostgreSQL for analysis and connected to Power BI for visualization.

## Database Structure

The project contains two primary tables:

* `cust_detail` – Customer-related information.
* `cc_detail` – Credit card and transaction-related information.

Additional weekly data is imported into the respective tables.

## Project Workflow

1. Collect and inspect the CSV datasets.
2. Create the PostgreSQL database and tables.
3. Import the customer and credit card data.
4. Execute SQL queries for data analysis.
5. Connect the data to Power BI.
6. Create interactive dashboard visualizations.
7. Analyze customer and transaction-related insights.

## Dashboard Analysis

The dashboard covers areas such as:

* Total revenue and interest earned.
* Revenue trends over time.
* Revenue by gender and age group.
* Card category performance.
* Customer job and income analysis.
* Geographic and demographic analysis.
* Customer satisfaction and dependent count.
